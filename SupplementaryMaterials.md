# Supplementary Materials: Standard qPCR

## qPCR assay design

Quantitative real-time PCR (qPCR) was performed using a QuantStudio 6 Real-Time PCR System (Thermo Fisher Scientific). Individual hydrolysis probe assays were used to quantify `FCGR2A`, `FCGR2B`, `FCGR2C`, `FCGR3A`, and `FCGR3B`. Each `FCGR2/3` target assay was analysed in a FAM labelled qPCR reaction. A VIC labelled `RNase P` assay was included as the reference assay. `RNase P` was measured in the same wells and used to normalise DNA input for subsequent copy number analysis. Genomic DNA was used as the template at a concentration of 10 ng/reaction, and the qPCR reactions were prepared using the GoTaq® Probe qPCR and RT-qPCR System (Promega, Madison, WI, USA). Fluorescence was acquired during the 60°C annealing/extension step using the FAM optical filter for `FCGR2/3` target assays and the VIC optical filter for the `RNase P` reference assay.

## QuantStudio 6 (QS6) cycling program

Standard cycling protocol was programmed on the QS6 system:

| Standard Cycling Step | Cycles | Temperature | Time |
|------|------:|------|------|
| GoTaq® Hot Start Polymerase activation | 1 | 95°C | 2 minutes |
| Denaturation | 40 | 95°C | 15 seconds |
| Annealing / Extension | 40 | 60°C | 60 seconds |
